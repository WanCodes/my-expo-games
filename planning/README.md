## Planning Folder

This folder centralizes high-level guidance for this React Native (Expo) app.

- Purpose:
  - Document how the app should be built and evolved.
  - Capture AI-facing instructions so future agents follow the same vision.
  - Store best practices, patterns, and architecture decisions.

- Structure:
  - `ai-instructions.md` – instructions for AI assistants on how to work in this repo.
  - `architecture-and-planning.md` – app goals, roadmap, and technical design.
  - `best-practices.md` – coding standards, UX guidelines, and performance tips.
  - `design-patterns.md` – recommended patterns for screens, navigation, and state.

Keep these documents up to date as the project grows.
