## Tasks Folder

This folder contains **step‑by‑step, actionable task lists** for AI agents (and humans) that describe how to build out features in this multi‑game React Native (Expo) app.

- **Scope**:
  - Breaking down features into concrete implementation steps.
  - Focusing on *how* to build (implementation), while the `planning` folder focuses on *what* and *why*.

- **Current task files**:
  - `multi-game-app-overview.md` – overall tasks for turning this into a multi‑game app.
  - `navigation-between-games.md` – tasks for setting up navigation between games.
  - `game-tic-tac-toe.md` – detailed tasks for implementing the Tic‑Tac‑Toe game.

Add new markdown files in this folder as you introduce more games or major features.
